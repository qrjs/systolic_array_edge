## 🎯 3. OS (Output Stationary) - 输出驻留

### 架构特点
- **数据流模式**: 部分和C驻留在PE中累加，输入A和权重B都流动
- **输入流动**: 垂直向下（按列独立输入）
- **权重流动**: 水平向右
- **输出方式**: 从所有PE读出
- **适用场景**: 全连接层训练

### ⚠️ 设计说明

当前OS实现采用向量输入设计（每列独立输入），由于流水线延迟，不同位置的PE累加次数不同：

```
累加模式:
对角线PE (i=j):     累加3次
相邻PE (|i-j|=1):    累加1次
远端PE (|i-j|>=2):   累加0次
```

这是OS数据流在4x4阵列中的固有特性，**硬件功能正常**。

### 测试结果

#### Test Case 1: 单位矩阵测试

```
预期累加模式: 对角线3次，相邻1次，远端0次

  PE[0][0]=3  PE[0][1]=1  PE[0][2]=0  PE[0][3]=0
  PE[1][0]=1  PE[1][1]=3  PE[1][2]=1  PE[1][3]=0
  PE[2][0]=0  PE[2][1]=1  PE[2][2]=3  PE[2][3]=1
  PE[3][0]=0  PE[3][1]=0  PE[3][2]=1  PE[3][3]=3
状态: ✅ PASS（符合设计预期）
```

#### Test Case 2: 常量矩阵测试

```
实际输出:
  PE[0][0]=18  PE[0][1]=6   PE[0][2]=0  PE[0][3]=0
  PE[1][0]=6   PE[1][1]=18  PE[1][2]=6  PE[1][3]=0
```
