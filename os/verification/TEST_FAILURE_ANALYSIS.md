# 验证失败分析报告

## 测试结果

### Test 1: 单位矩阵
- 预期: [4, 4, 4, 4]
- 实际: [4, 4, 4, **3**] ❌
- 问题: output[3] = 3 而不是 4

### Test 2: 常量矩阵
- 预期: [24, 24, 24, 24]
- 实际: [24, 24, 24, **20**] ❌
- 问题: output[3] = 20 而不是 24

## 问题分析

### 可能的原因

1. **时序问题** (最可能)
   - 输出[3] 是最后一个稳定的数据
   - 捕获时间太早，数据还未完全传播

2. **数据流问题**
   - 最后一列 PE 的数据流有延迟
   - 权重/数据加载不完整

3. **设计问题**
   - systolic array 的实现有 bug
   - 边界条件处理不当

### 诊断建议

需要检查：
1. 增加等待时间，让所有输出完全稳定
2. 检查 systolic_array_4x4.v 中的数据流
3. 使用 GTKWave 查看波形，分析时序关系
