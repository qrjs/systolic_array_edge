# Systolic阵列架构设计文档

## 1. 概述

本文档描述面向边缘计算的4x4 Systolic阵列架构设计。该设计针对神经网络矩阵乘法运算进行了优化，具有低功耗、高吞吐量的特点。

### 1.1 设计目标

- **低功耗**: 面向边缘计算设备，功耗优化
- **高性能**: 支持高吞吐量矩阵乘法
- **可扩展**: 模块化设计，支持扩展到更大阵列
- **资源高效**: 针对FPGA/ASIC资源优化

### 1.2 应用场景

- 神经网络推理（CNN、RNN等）
- 图像处理（卷积运算）
- 信号处理（矩阵运算）
- 边缘AI加速

## 3. Processing Element (PE) 设计

### 3.1 PE功能

PE是Systolic阵列的基本计算单元，执行以下操作：

1. **MAC运算**: `output = partial_in + input × weight`
2. **权重存储**: 保持权重不变，减少访存
3. **数据流水**: 将输入数据传递给下一级PE

### 3.2 PE内部结构

```
         ┌─────────────┐
         │   Weight    │
         │   Register  │
         └──────┬──────┘
                │
    ┌───────┐  │  ┌───────────┐
    │ Input │  │  │           │
    │  →   ├──┴──→│    MAC    ├────→ Partial
    │ Data │     │ │  Unit     │       Sum Out
    └───────┘     │ └───────────┘
                  │
                  ↓
             (next PE)
```

### 3.3 PE端口说明

| 端口名 | 方向 | 位宽 | 描述 |
|--------|------|------|------|
| clk | input | 1 | 时钟信号 |
| rst_n | input | 1 | 低电平复位 |
| weight_in | input | 16 | 权重输入 |
| weight_valid | input | 1 | 权重有效信号 |
| weight_load | input | 1 | 权重加载控制 |
| input_data | input | 16 | 输入数据 |
| input_valid | input | 1 | 输入有效信号 |
| partial_in | input | 32 | 部分和输入 |
| partial_in_valid | input | 1 | 部分和有效 |
| partial_out | output | 32 | 部分和输出 |
| partial_out_valid | output | 1 | 输出有效信号 |
| input_out | output | 16 | 数据输出给下一级 |

## 4. Systolic阵列组织

### 4.1 阵列参数

- **规模**: 4×4 PE阵列
- **数据位宽**: 16位定点数
- **累加位宽**: 32位
- **运算**: 矩阵乘法 C = A × B

### 4.2 数据流设计

#### 4.2.1 输入数据流（水平方向）

```
A[0][0] → PE[0][0] → PE[0][1] → PE[0][2] → PE[0][3]
A[1][0] → PE[1][0] → PE[1][1] → PE[1][2] → PE[1][3]
A[2][0] → PE[2][0] → PE[2][1] → PE[2][2] → PE[2][3]
A[3][0] → PE[3][0] → PE[3][1] → PE[3][2] → PE[3][3]
```

#### 4.2.2 部分和数据流（垂直方向）

```
                    ↓          ↓          ↓          ↓
                  PE[0][0]   PE[0][1]   PE[0][2]   PE[0][3]
                    ↓          ↓          ↓          ↓
                  PE[1][0]   PE[1][1]   PE[1][2]   PE[1][3]
                    ↓          ↓          ↓          ↓
                  PE[2][0]   PE[2][1]   PE[2][2]   PE[2][3]
                    ↓          ↓          ↓          ↓
                  PE[3][0]   PE[3][1]   PE[3][2]   PE[3][3]
                    ↓          ↓          ↓          ↓
                   C[0][?]   C[1][?]    C[2][?]    C[3][?]
```

### 4.3 时序设计

#### 4.3.1 流水线阶段

1. **权重加载阶段**: 加载权重到各PE
2. **数据输入阶段**: 输入矩阵A的数据流入阵列
3. **计算阶段**: PE执行MAC运算
4. **输出阶段**: 结果从阵列底部流出

### 5.2 接口时序

#### 5.2.1 握手协议

- **Valid-Ready握手**: 所有数据接口使用valid-ready握手协议

## 6. 性能指标

### 6.1 理论性能

- **吞吐量**: 每周期4次MAC运算
- **延迟**: 约(N + M - 1)个周期（N为矩阵维度，M为流水线深度）
- **峰值性能**: @100MHz: 400 MMAC/s

### 6.2 资源估算

| 资源类型 | 数量 | 说明 |
|---------|------|------|
| DSP单元 | 16 | 16个乘法器 |
| 寄存器 | ~500 | PE内部寄存器 |
| LUT | ~2000 | 控制和路径逻辑 |

### 6.3 功耗估算

- **动态功耗**: 主要来自MAC运算
- **静态功耗**: 寄存器保持功耗
- **优化策略**: 时钟门控、数据复用

## 7. 扩展性设计

### 7.1 参数化设计

所有模块使用参数化设计，支持：

- 可配置阵列大小
- 可配置数据位宽
- 可配置累加位宽

### 7.2 扩展方向

1. **水平扩展**: 增加列数，支持更大矩阵
2. **垂直扩展**: 增加行数，提高并行度
3. **级联扩展**: 多个阵列级联

## 8. 设计权衡

### 8.1 面积 vs 性能

- **选择**: 牺牲一定面积换取高吞吐量
- **理由**: 边缘计算需要实时性能

### 8.2 功耗 vs 速度

- **选择**: 降低工作频率，优化功耗
- **理由**: 边缘设备功耗预算有限

### 8.3 灵活性 vs 效率

- **选择**: 针对矩阵乘法优化，牺牲通用性
- **理由**: 专用加速器应该高度优化

## 10. 后续优化方向

1. **稀疏矩阵优化**: 支持稀疏神经网络
2. **量化优化**: 支持更低精度（8位、4位）
3. **融合运算**: MAC+激活函数融合
4. **片上存储**: 集成本地缓存
5. **功耗管理**: 动态电压频率调整（DVFS）
