## 使用方法

### 快速验证（Icarus Verilog）

```bash
cd ~/systolic_array_edge
iverilog -g2012 -o sim/work/direct_sim \
    src/pe.v \
    src/systolic_array_4x4.v \
    tb/direct_array_tb.v
cd sim/work
vvp direct_sim
surfer direct_array_tb.vcd
```

### VCS仿真

```bash
cd ~/systolic_array_edge/sim
./run_sim.sh run
```
