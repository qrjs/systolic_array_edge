# 论文大纲（面向边缘计算的脉动阵列）

## 题目建议

面向边缘计算的多数据流脉动阵列设计与验证：传统 WS/IS/OS 对比及 DiP 复现

---

## 摘要（写作要点）

1. 研究背景：边缘设备受限于功耗、带宽与面积。  
2. 核心问题：不同数据流对资源/时序/能效影响差异。  
3. 方法：统一实现 WS/IS/OS/DIP，并建立统一验证与综合流程。  
4. 结果：给出功能回归结果与综合指标对比。  
5. 结论：总结 DiP 与传统数据流在边缘场景的适用边界。

---

## 创新点（建议写法）

> 说明：本论文的创新点不宜表述为“提出全新数据流”，而应聚焦于“统一平台、边缘优化、后端分析方法”。

1. 新提出一套面向边缘计算的多数据流脉动阵列统一实现与评估方法  
- 在统一 RTL 框架、统一验证向量、统一约束条件下，对 `WS/IS/OS/DIP` 四类数据流进行公平比较。  
- 创新性体现在“统一比较框架”和“可复现实验流程”，而不是重新发明数据流本身。

2. 新提出一组面向边缘低功耗场景的轻量化脉动阵列优化策略  
- 包括 `valid-gating`、`zero-gating`、无效周期寄存保持、控制路径寄存化等。  
- 在不改变核心计算语义的前提下，降低无效翻转，提升边缘场景下的能效表现。

3. 新提出一种从物理实现角度分析数据流差异的方法  
- 不仅比较功能和综合结果，还比较 post-route 时序、关键路径和功耗特征。  
- 说明数据流选择不仅影响算法映射，也直接影响物理实现质量与边缘部署可行性。

4. 若后续补全 ASIC 后端流程，可进一步提升为：  
- 新提出面向边缘计算的脉动阵列数据流 ASIC 级公平评估流程。  
- 在统一工艺库、统一时钟约束、统一面积与功耗指标下，对传统数据流与 DiP 进行标准单元级比较。
