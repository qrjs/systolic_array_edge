# Systolic阵列详细资源评估报告

## 1. 资源使用详细分析

### 1.1 Processing Element (PE) 资源

单个PE的资源使用（基于代码分析）：

| 资源类型 | 数量 | 说明 |
|---------|------|------|
| **寄存器** | 15 | |
| - 权重寄存器 | 1 | 16位权重存储 |
| - 输入寄存器 | 2 | 输入和输出数据寄存器 |
| - 部分和寄存器 | 2 | 部分和输入和输出 |
| - 累加器 | 1 | 32位累加器 |
| - 控制寄存器 | 3 | 处理、停顿、有效标志 |
| - 其他 | 6 | 地址、计数器等 |

### 1.2 Systolic阵列资源

16个PE阵列的资源使用：

| 资源类型 | PE部分 | 互联部分 | 总计 |
|---------|--------|---------|------|
| DSP单元 | 16 | - | 16 |
| 寄存器 | 240 | 50 | 290 |
| LUT | 1280 | 278 | 1558 |

**说明**：
- DSP单元：每个PE一个乘法器，共16个
- 寄存器：16个PE × 15个/PE + 控制和互联寄存器
- LUT：16个PE × 80个/PE + 互联和控制逻辑

## 3. 性能指标详细分析

### 3.1 计算性能

#### 吞吐量分析

```
单个PE吞吐量：1 MAC/cycle
4×4阵列吞吐量：16 MAC/cycle
@100MHz：1.6 GMAC/s
```

#### 延迟分析

| 阶段 | 周期数 | 时间(ns) | 说明 |
|------|--------|----------|------|
| 权重加载 | 16 | 160 | 16个权重 |
| 输入加载 | 16 | 160 | 16个输入 |
| 流水线填充 | 6 | 60 | 4+2周期 |
| 流水线排空 | 4 | 40 | 输出结果 |
| **总延迟** | **42** | **420** | **完整矩阵乘法** |

#### 持续吞吐量

稳态情况下：
- 每4个周期可以完成一个4×4矩阵乘法
- 吞吐量：0.25 矩阵/周期 = 25M矩阵/秒@100MHz

### 3.2 频率分析

#### 关键路径分析

1. **PE内部关键路径**
   - 路径：输入寄存器 → 乘法器 → 加法器 → 输出寄存器
   - 延迟估算：~8ns
   - 最高频率：~125MHz

2. **阵列间关键路径**
   - 路径：PE输出 → 互联 → 下个PE输入
   - 延迟估算：~2ns
   - 最高频率：~500MHz

3. **整体关键路径**
   - 由PE内部决定
   - 保守频率：100MHz
   - 优化后可达：150MHz

### 3.3 功耗分析

#### 静态功耗

| 来源 | 功耗(mW) | 说明 |

| 漏电流 | 5 | 晶体管漏电 |

#### 功耗优化建议

1. **时钟门控**
   - 空闲PE可以关闭时钟
   - 节省30-50%动态功耗

2. **电压缩放**
   - 降低工作电压
   - 功耗随电压平方降低

3. **数据复用**
   - 已实现：权重静态存储
   - 减少75%的访存功耗

## 8. 优化建议

### 8.1 性能优化

1. **增加阵列规模**
   - 扩展到8×8：6.4 GMAC/s
   - 资源占用仍可接受

2. **提升工作频率**
   - 流水线优化
   - 关键路径优化
   - 目标：150-200MHz

3. **稀疏化优化**
   - 跳过零值计算
   - 提升2-4倍有效性能

### 8.2 功耗优化

1. **时钟门控**
   - 实现：添加时钟使能
   - 效果：节省30-50%功耗

2. **数据通路门控**
   - 空闲时关闭数据通路
   - 效果：节省20%功耗

3. **多电压域**
   - 计算单元高电压
   - 存储单元低电压
   - 效果：节省15%功耗

### 8.3 面积优化

1. **资源共享**
   - 部分和累加器共享
   - 效果：节省20%寄存器

2. **时域复用**
   - 分时复用PE
   - 效果：减少50%PE数量
